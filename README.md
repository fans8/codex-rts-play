# Codex RTS

A browser RTS built in collaboration with OpenAI Codex throughout development.

[Play Codex RTS](https://fans8.github.io/codex-rts-play/)

Release: **2026.09.24-r5**. This repository contains the current compiled game and deployment configuration. Publishing is manual; commits do not automatically deploy.

Known issues: intermittent persistent slowdowns in normal matches; slow or stalled loading on some public connections and delayed first-use unit/action textures are under separate R5 investigation.

This development release is published for Owner testing, not final product acceptance. F3/F4 diagnostics remain available; FPS is shown during play. Known first-placement and long-session performance issues remain open.
